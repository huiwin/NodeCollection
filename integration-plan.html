subconverter + jichangnodes integration plan v3.0

Overview

This document describes how to integrate subconverter (subscription format converter) and jichangnodes (airport node list) into your existing NodeCollection project. The goal is to add multi-format output (Clash/V2Ray/Surge/SingBox) and expanded data sources while keeping the existing code structure stable.

1.4 Key design decisions

Why self-host subconverter instead of public API?

  • Reliability: Public subconverter APIs frequently go offline or rate-limit
  • Speed: Local API call takes <1s vs 5-15s for remote
  • Privacy: Subscription URLs are not leaked to third parties
  • Cost: Free in GitHub Actions, no VPS needed

Why probe airports instead of auto-register?

  • Phase 1 focuses on stability - probing public pages is non-destructive
  • Auto-registration requires temp email, captcha solving, fragile
  • Phase 2 adds v2board API registration for known airport types
  • Airports that support Clash are prioritized in airports.yaml

Backward compatibility guarantee

  • config.yaml format unchanged (tgchannel list)
  • Output YAML format unchanged (4 keys: airport/clash/v2/play)
  • sub/ directory structure unchanged (YYYY/M/M-D.yaml)
  • If subconverter is unavailable, raw YAML still produced
  • If airports.yaml is missing, TG-only crawling still works

3. Phased implementation roadmap

1

Phase 1: Basic integration (current - delivered)

Goal: Add subconverter multi-format output + airport probing, keep existing flow intact.

Deliverables:

  • main.py v3.0 with load_airports(), probe_airport(), call_subconverter(), generate_multi_format()
  • airports.yaml with 50+ curated airport domains
  • subconverter/external_config.ini with ACL4SSR rules + proxy groups
  • GitHub Actions workflow with subconverter binary download/start/stop
  • output/ directory with clash/v2ray/surge/mixed subdirectories
  • index.json with latest output file paths

Acceptance criteria:

  • GitHub Actions run completes with all steps green
  • sub/YYYY/M/D.yaml produced (backward compatible)
  • output/clash/M-D.yaml contains valid Clash config with proxies + rules + groups
  • output/v2ray/M-D.txt contains base64-encoded node list
  • output/index.json has correct file paths and timestamp
2

Phase 2: Automation enhancement (2-4 weeks)

Goal: Auto-register v2board airports, expand data sources, add health metrics.

Deliverables:

  • v2board auto-registration module (temp email + POST /api/v1/passport/auth/register)
  • Subscription URL caching (avoid re-registration each run)
  • Node count tracking per subscription (filter empty)
  • Latency test integration (subconverter sort + url-test)
  • Sing-box format output (add sing-box target)
  • Daily statistics report (nodes collected, success rate, by region)

Acceptance criteria:

  • At least 10 airports auto-registered per run
  • Subscriptions with 0 nodes are filtered out
  • Clash output nodes sorted by latency (fastest first)
  • Sing-box config valid and importable
3

Phase 3: Performance and stability (4-8 weeks)

Goal: Scale to 200+ airports, add monitoring, optimize resource usage.

Deliverables:

  • asyncio + aiohttp migration (replace threading)
  • SQLite database for subscription history (track node count, latency over time)
  • Telegram bot notification on run completion/failure
  • Web dashboard (Flask) for browsing collected nodes
  • Docker deployment option (for VPS users)
  • Automatic airport discovery (scan TG channels for new airport domains)

Acceptance criteria:

  • Full run completes in <60s (currently ~90s)
  • Telegram notification sent within 30s of completion
  • Web dashboard shows node history graph
  • Docker image <50MB

5.4 Key code: load_airports()

def load_airports():
    """
    读取 airports.yaml 机场列表。
    返回: list[dict] 每项含 domain, clash(可选), note(可选)
    """
    if not os.path.isfile(AIRPORTS_PATH):
        logger.info('未找到 airports.yaml，跳过机场探测')
        return []

    with open(AIRPORTS_PATH, encoding='UTF-8') as f:
        data = yaml.load(f, Loader=yaml.FullLoader)

    airports = data.get('airports', []) if data else []
    logger.info(f'读取机场列表: {len(airports)} 个')
    return airports

5.5 Key code: probe_airport()

def probe_airport(session, airport):
    """
    探测单个机场域名的公开订阅链接。

    策略:
      1. 访问 https://{domain}/ 页面
      2. 正则提取页面中所有 URL
      3. 过滤出含订阅关键词的链接
      4. 返回候选订阅 URL 列表

    注意: 此为 Phase 1 简单实现，不包含自动注册。
    Phase 2 将增加 v2board API 自动注册获取试用订阅。
    """
    domain = airport.get('domain', '').strip()
    if not domain:
        return []

    # 标准化域名为完整 URL
    if not domain.startswith('http'):
        domain = f'https://{domain}'

    if not is_safe_url(domain):
        return []

    candidate_urls = []
    try:
        resp = session.get(domain, timeout=AIRPORT_TIMEOUT, allow_redirects=True)
        page_urls = URL_REGEX.findall(resp.text)

        for url in page_urls:
            if not is_safe_url(url):
                continue
            # 检查 URL 或路径是否包含订阅关键词
            if SUB_KEYWORDS.search(url):
                candidate_urls.append(url)

        # 也检查页面文本中的 base64 编码内容 (可能包含节点链接)
        # 这里保持简单，不做 base64 解码

    except requests.Timeout:
        logger.debug(f'[airport] {domain}\t超时')
    except requests.ConnectionError:
        logger.debug(f'[airport] {domain}\t连接失败')
    except Exception as e:
        logger.debug(f'[airport] {domain}\t{type(e).__name__}: {e}')

    if candidate_urls:
        logger.info(f'[airport] {domain}\t发现 {len(candidate_urls)} 个候选订阅')
    return candidate_urls

5.6 Key code: call_subconverter()

def call_subconverter(target, sub_urls, output_path):
    """
    调用 subconverter API 转换订阅格式。

    Args:
        target: 目标格式 (clash, v2ray, surge&ver=4, mixed 等)
        sub_urls: 订阅 URL 列表
        output_path: 输出文件路径
    """
    if not sub_urls:
        logger.warning(f'[{target}] 订阅 URL 为空，跳过')
        return False

    # 用 | 合并多个订阅 URL，然后 URL-encode
    merged_url = '|'.join(sub_urls)
    encoded_url = quote(merged_url, safe='')

    # 构造外部配置路径 (使用绝对路径)
    config_path = os.path.abspath(SUBCONVERTER_EXTERNAL_CONFIG)
    encoded_config = quote(f'file://{config_path}', safe='')

    api_url = (
        f'{SUBCONVERTER_URL}/sub?'
        f'target={target}&'
        f'url={encoded_url}&'
        f'config={encoded_config}&'
        f'emoji=true&'
        f'udp=true&'
        f'tfo=false&'
        f'expand=true&'
        f'append_info=true&'
        f'sort=false'
    )

    try:
        resp = requests.get(api_url, timeout=SUBCONVERTER_TIMEOUT)
        if resp.status_code == 200 and resp.text.strip():
            # 确保输出目录存在
            os.makedirs(os.path.dirname(output_path), exist_ok=True)
            with open(output_path, 'w', encoding='utf-8') as f:
                f.write(resp.text)
            logger.info(f'[{target}] 转换成功 → {output_path} ({len(resp.text)} bytes)')
            return True
        else:
            logger.warning(f'[{target}] 转换失败: HTTP {resp.status_code}')
            return False
    except requests.Timeout:
        logger.warning(f'[{target}] subconverter 请求超时')
        return False
    except Exception as e:
        logger.warning(f'[{target}] subconverter 异常: {type(e).__name__}: {e}')
        return False

5.7 Key code: generate_multi_format()

def generate_multi_format(all_sub_urls):
    """
    将所有订阅 URL 通过 subconverter 转换为多格式输出。

    Args:
        all_sub_urls: 所有有效订阅 URL 的列表
    """
    if not check_subconverter():
        logger.warning('subconverter 不可用，仅输出原始 YAML')
        return

    today = datetime.datetime.today()
    date_str = f'{today.year}/{today.month}/{today.month}-{today.day}'

    for target, subdir, ext in OUTPUT_FORMATS:
        output_path = os.path.join(
            OUTPUT_DIR, subdir,
            f'{today.month}-{today.day}.{ext}'
        )
        call_subconverter(target, all_sub_urls, output_path)

    # 额外: 生成一个合并所有格式的 index.json 索引文件
    index_path = os.path.join(OUTPUT_DIR, 'index.json')
    index_data = {
        'update_time': datetime.datetime.now().strftime('%Y-%m-%d %H:%M:%S'),
        'date': date_str,
        'formats': {},
        'total_urls': len(all_sub_urls),
    }
    for target, subdir, ext in OUTPUT_FORMATS:
        fname = f'{today.month}-{today.day}.{ext}'
        index_data['formats'][target] = f'{subdir}/{fname}'

    with open(index_path, 'w', encoding='utf-8') as f:
        json.dump(index_data, f, ensure_ascii=False, indent=2)
    logger.info(f'索引文件: {index_path}')

6.1 Compliance notes

  • This project collects publicly available subscription links from Telegram channels and airport websites
  • It does not crack, bypass, or steal paid services
  • Airport probing only visits public pages - no authentication bypass
  • Users are responsible for complying with local laws and regulations
  • Node quality is not guaranteed - use at your own risk

6.2 Fallback strategy

subconverter unavailable?
  -> main.py detects via check_subconverter()
  -> skips generate_multi_format()
  -> still produces sub/YYYY/M/D.yaml (raw)
  -> logs warning, Actions run still succeeds

airports.yaml missing?
  -> load_airports() returns []
  -> probe_all_airports() returns []
  -> TG-only crawling proceeds normally

All airports fail to probe?
  -> 0 candidate URLs from airports
  -> TG URLs still validated and classified
  -> output produced from TG sources only
